# Epics

## Phase 0 - MVP

#### Goals

1. Content is submitted in a admin application. 
2. Content is presented in the product's main application

#### Details

1. The admin application:  
1.1. allows to submit picture files  
1.2. allows to manage content (edit, delete and toggle visibility)  
2. The product's application:  
2.1. shows the public content (in masonry style only)  
2.2. allows visitors to filter content (by category and date)
