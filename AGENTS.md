# Project Instructions

## General

- Read the requirements before implementing anything.
- Do not implement functionality that is not required.
- Prefer simple solutions over unnecessary abstractions.
- Do not modify unrelated code.
- Ask for clarification when requirements are ambiguous.

## Development

- Follow the architecture defined in docs/architecture.md.
- Add tests for new functionality.
- Do not introduce dependencies without justification.
- Run the project's tests before considering a task complete.

## Git

- Work on a feature branch.
- Keep commits focused.
- Do not commit secrets.
- Every feature should be associated with a GitHub Issue.
- Pull requests must explain what changed and how it was tested.
